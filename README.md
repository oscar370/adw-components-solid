A collection of Adwaita-based Solid components.

[Docs](https://adw-components-solid.netlify.app/)

## Installation

### Prerequisites

You must have **TailwindCSS** configured beforehand.

Then, install the following dependencies:

```bash
# embla-carousel-solid is only required if you use the carousel component
# sonner is only required if you use the toast component
pnpm add class-variance-authority clsx tailwind-merge lucide-solid solid-sonner embla-carousel-solid
```

### Manual Installation

Copy and paste the specific components you need from this [repository](https://github.com/oscar370/adw-components-react-core).

### Degit

Degit is a tool that allows you to clone the components directly from the repository without downloading the Git history.

```bash
npx degit oscar370/adw-components-react-core src
```
